## 🎨 Melhorias de Código

### Type Hints
```python
# Antes:
numero = int(input(...))

# Depois:
numero: int = int(input(...))
```

### Docstrings
```python
def exercicio_1() -> None:
    """
    Exercício 1: Descrição clara.
    Faz exatamente X.
    """
```

### Tratamento de Erros
```python
try:
    valor: float = float(input(...))
except ValueError:
    print("Erro: Digite um valor válido!")
```
